# Power-BI-Sales-Analytics-Project-Adventure-Works
Designed and delivered an advanced, interactive Power BI dashboard for Adventure Works sales data. Performed ETL, Data modeling, DAX, visualization and advanced visualization using AI tools. Integrating executive-level KPIs (revenue, profit, orders, returns), customer segmentation via logistic regression, and trend forecasting. Developed insightful visuals including decomposition trees, seasonality matrix, and key influencers using AI-driven analytics to uncover sales drivers. Enabled data-driven strategic decisions by analyzing regional sales performance, product trends, and customer behavior, resulting in actionable insights to improve revenue and marketing effectiveness.
